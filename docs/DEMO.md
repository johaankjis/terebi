# DEMO

Hard limit: **under 90 seconds**. Show the plugin working on real hardware. Film the TV with a second camera; the TV starting by itself is the shot that sells it.

## Setup before recording

- Jellyfin library with legal content and good posters (Blender open movies + public domain classics).
- Seed history: finish one or two shorts, stop Sintel partway, start a series so Next Up exists.
- Roku on the Home screen, TV on (or off if power on works on your Roku TV).
- Phone with Telegram open to Hermes.
- Run the full flow 3 times off camera.
