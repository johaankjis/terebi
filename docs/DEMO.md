# DEMO

Hard limit: **under 90 seconds**. Show the plugin working on real hardware. Film the TV with a phone or second camera; the TV turning on by itself is the shot that sells it.

## Setup before recording

- TV off (or on Roku home), phone with Telegram open to Hermes.
- Seed taste history so reasons look real (a couple of finished comedies, two abandoned dramas).
- Run the full flow 3 times off camera first.
- Screen recorder running on the phone; second camera on the TV.

## Script

| Time | Shot | Action / line |
|---|---|---|
| 0:00 to 0:08 | Couch, TV off | Title card: "Hermes Screen: give Hermes a TV" |
| 0:08 to 0:15 | Phone | Type: "we have 45 minutes, something funny" |
| 0:15 to 0:30 | Phone | Hermes replies with 3 picks, each with a one line reason that references past behavior |
| 0:30 to 0:45 | Split: phone + TV | Reply "2". **TV switches on and the title starts playing** |
| 0:45 to 0:55 | Phone + TV | "pause it" → TV pauses |
| 0:55 to 1:15 | Phone + TV | "show me how to fold a fitted sheet on the TV" → YouTube casts at the right timestamp |
| 1:15 to 1:25 | Card | "Learns from what you finish and abandon. Roku + Chromecast. Install from the Hermes Marketplace." + GitHub link |
